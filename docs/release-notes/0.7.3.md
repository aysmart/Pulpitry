Pulpitry would not start on a Windows machine without a Vulkan driver.

## "vulkan-1.dll was not found"

Pulpitry uses your graphics card to transcribe where there is one, through
Vulkan. Building it that way put a requirement for `vulkan-1.dll` into the
program itself — so on a machine with no Vulkan driver, usually an older one,
Windows refused to start Pulpitry at all and said so in those words.

It was not that transcription would be slower on those machines. The
application did not open.

The Vulkan loader now ships with Pulpitry. On a machine with a graphics driver
nothing changes; on a machine without one, Pulpitry starts and transcribes on
the processor, which is what it was always going to do there anyway.

If you met this, install this version over the old one — nothing is lost.

---

Not code signed. macOS will refuse to open it until you right-click and choose
Open; Windows SmartScreen will warn.

The engine that runs on your own machine needs no Node runtime. Azure and
Castavox subscriptions still need Node 20 or later, which is not bundled.
Scripture, songs, slides and the projector work without it.
