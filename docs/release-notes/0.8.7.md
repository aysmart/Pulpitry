Permissions that survive updates.

## Signed, so macOS knows it is still Pulpitry

Pulpitry for Mac is now signed with a certificate of its own, so macOS
recognises each update as the same application. Until now every update was a
stranger to it: Screen Recording and the microphone were asked for again, and
System Settings went on showing the old permission switched on while refusing
the new version — which is why a network feed could come up blank after an
update, with the permission it needed still ticked.

**This update asks once more** — for Screen Recording the first time you open a
network feed, and for the microphone the first time you listen. Allow them,
reopen Pulpitry, and later updates keep them.

If System Settings already shows Pulpitry switched on and the feed still says
permission is missing, select Pulpitry in the Screen & System Audio Recording
list, remove it with the minus button, then open the feed again and allow it.
