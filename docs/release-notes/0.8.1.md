## The check-in is no longer optional

Pulpitry sends a short note once a day saying this installation exists. There is
no switch for it any more, and Settings says so rather than offering one.

Why: a count of only the churches who agreed to be counted is not a count. It is
a floor with an unknown gap above it, and every decision made from it is wrong
in the same direction.

What it carries is unchanged, and is listed in Settings under Help: a random
identifier made on this machine, which application and version, the operating
system, what kind of processor it has, which transcription engine you chose, and
how many summaries and slide sets this installation has made. Two counts, and
nothing about what is in either. Your country is worked out from the connection
and the address is discarded.

What it has never carried, and still does not: this machine's name, your
address, or a transcript, a verse, a reference or a filename. There is no field
in it for any of those.

If you would rather not be counted, write to support@castavox.com and we will
delete what is held against your installation. Deleting the `install-id` file
beside Pulpitry's data makes this machine a new installation to us.

The privacy policy has been updated to say all of this, and was published before
this release.
