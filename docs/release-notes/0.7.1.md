The release that makes 0.7.0's updater work.

0.7.0 added self-updating and shipped without the manifest it reads: the build
produced every signature and uploaded none of them, so there was nothing for an
installed copy to find. This publishes it.

Nothing else has changed. **This is still a release you install by hand** — from
here on, Pulpitry keeps itself current.

---

Not code signed. macOS will refuse to open it until you right-click and choose
Open; Windows SmartScreen will warn.

The engine that runs on your own machine needs no Node runtime. Azure and
Castavox subscriptions still need Node 20 or later, which is not bundled.
Scripture, songs, slides and the projector work without it.
