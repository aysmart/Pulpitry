## A machine takes over from itself

A session outlives anything that is not a clean stop — a crash, a lid shut on a
sleeping laptop, a force-quit because the screen froze two minutes before the
service. The subscription counted those as machines still listening, so starting
again was refused with "all your slots are in use", against nobody but yourself.

Starting now closes whatever this same machine left open and carries on. Two
different machines still compete for slots as before, and a Pulpitry with a
Castavox drawing from it is still two sessions on one desk, on purpose.

## Sessions that were closed now stop

A session ended on the subscription page never actually stopped the machine it
belonged to. It kept listening and kept sending audio, while the subscription
had stopped recording any of it.

It stops now, and says so.
