Subscriptions work on Windows. This is the release to install.

## Why listening never started

A Windows machine on a subscription would say it was reconnecting, over and
over, and never transcribe a word. The message blamed the network, and the
network was fine — the same connection had activated the licence minutes
earlier.

The speech engine runs on Node, and Pulpitry was handing it the path to its own
script in a form Windows understands and Node does not. Node refused the script
before running a line of it and exited. Pulpitry saw a program that had stopped,
could not say why, and tried again. That loop is the whole of what people were
seeing.

This affected every Windows installation using an Azure or Castavox
subscription. Nothing was wrong with any of those machines, their networks, or
their subscriptions. It is fixed.

The engine that runs on your own machine was never affected, because it does not
use Node.

## When something does go wrong, it now says what

Chasing this took far longer than it should have, because Pulpitry had the
answer written in its log the entire time and showed "stopped unexpectedly" on
screen instead.

The speech engine's own words now reach you. A rejected key, a runtime that will
not load, a connection the service closed — whatever it says, you see. When it
is stopped without a word, which is what antivirus does, that is reported too,
and it is a different sentence, because it points somewhere different.

## Also in this release

Pulpitry starts on a Windows machine with no Vulkan driver. 0.7.3 shipped the
Vulkan loader into a folder Windows does not search when starting a program, so
the machines that could not open Pulpitry still could not open it. On Windows,
transcription on your own machine now runs on the processor and needs no
graphics driver at all.

That is slower on a Windows PC with a usable graphics card. Settings tells you
what your machine actually manages, and a subscription is the answer for one
that cannot keep up. We would rather be slower everywhere than fastest on some
machines and dead on others. Using the graphics card again is work we will do
properly rather than guess at a third time.

Castavox is unaffected by all of this: its speech engine is a separate program
that resolves its own paths and keeps its Vulkan loader where Windows looks.
